# Веб-додаток для обміну книгами

## Опис проекту
Веб-додаток створено для обміну книгами між користувачами. Він дозволяє знаходити книги для обміну, переглядати доступні пропозиції, додавати власні книги та замовляти книги у інших користувачів.
- **Backend:** Node.js, Express.js, MongoDB

---

## Інструкція для запуску додатку

### Клонування проекту
Для початку склонуйте репозиторій до своєї локальної машини:
```bash
git clone https://github.com/protsenkoveronika/node-project.git
```

### Запуск Backend
1. Перейдіть до папки **`server`**, яка містить код для Backend.
   ```bash
   cd server
   ```
2. Встановіть залежності:
   ```bash
   npm install
   ```
3. Налаштуйте файл `.env`, додавши необхідні змінні середовища.

4. Запустіть сервер за допомогою команди:
   ```bash
   node run dev
   ```
